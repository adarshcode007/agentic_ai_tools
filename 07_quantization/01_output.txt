======================================================================
  PART 5: INDUSTRY QUANTIZATION FORMATS (GGUF vs AWQ vs BITSANDBYTES)
======================================================================
1. GGUF (llama.cpp):
   * Target Hardware: CPU + System RAM (Mac Metal, Windows, Linux).
   * How it works: Single binary file containing model weights + tokenizer metadata.
   * Best for: Edge devices, laptops without NVIDIA GPUs, and Ollama.

2. AWQ (Activation-aware Weight Quantization):
   * Target Hardware: NVIDIA GPUs (vLLM, TensorRT-LLM).
   * How it works: Protects the top 1% 'salient' weights in full precision;
     quantizes the remaining 99% to INT4.
   * Best for: Ultra-high throughput cloud serving.

3. bitsandbytes (NF4 - NormalFloat4):
   * Target Hardware: NVIDIA GPUs (Hugging Face transformers, QLoRA).
   * How it works: Non-linear quantization optimized for Gaussian-distributed weights.
   * Best for: Fine-tuning local LLMs on a single consumer GPU (e.g. RTX 3060/4090).
